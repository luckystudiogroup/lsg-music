LUCKY STUDIO MUSIC — GitHub Pages starter

1. Buat repository GitHub bernama lsg-music (Public).
2. Upload index.html ke root repository.
3. Buka Settings > Pages.
4. Pada Build and deployment pilih Deploy from a branch, branch main, folder / (root), lalu Save.
5. URL biasanya: https://USERNAME.github.io/lsg-music/

MENAMBAHKAN LAGU:
Buka index.html, cari const TRACKS = [ lalu isi data lagu resmi LSG.
Format:
{ title: 'Judul Lagu', artist: 'LUCKY STUDIO MUSIC', audio: 'audio/judul.mp3', cover: 'covers/judul.jpg', category: 'Pop' }

Buat folder audio dan covers di repository, lalu upload file milik LSG ke folder tersebut.
Jangan gunakan file audio atau poster yang tidak memiliki izin publikasi.
